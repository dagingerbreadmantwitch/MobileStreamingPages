# Media Assets Directory for MobileStream Studio

Place your Rive animations and WebM video files in this folder to test with the Browser Source Overlay and Media Remote:

- **`animation.riv`**: Rive vector animation file.
- **`video1.webm`**: WebM video asset #1 (supports transparent alpha channel videos).
- **`video2.webm`**: WebM video asset #2 (supports transparent alpha channel videos).

---
You can also use custom local paths or external URLs directly from the **Media Remote Control** page (`pages/media-remote.html`).
